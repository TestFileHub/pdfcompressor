# PDF Compressor

A modern, minimalistic web application for compressing PDF files directly in your browser.

## Features

- **Client-Side Processing**: All compression happens in your browser - no files are uploaded to any server
- **Privacy First**: Your files never leave your device
- **Multiple Compression Levels**: Choose between Low, Medium, and High compression
- **Drag and Drop**: Easy file upload with drag-and-drop support
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, minimalistic interface with smooth animations
- **Real-time Progress**: Visual feedback during compression

## How to Use

1. Visit the website
2. Click "Choose File" or drag and drop a PDF file
3. Select your desired compression level (Low, Medium, or High)
4. Click "Compress PDF"
5. Download your compressed PDF file

## Technology Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript**: Vanilla JS for functionality
- **PDF-lib**: Client-side PDF manipulation library

## Local Development

Simply open `index.html` in a modern web browser. No build process or server required.

## GitHub Pages Deployment

This site is designed to be hosted on GitHub Pages. To deploy:

1. Push your code to a GitHub repository
2. Go to repository Settings → Pages
3. Select the branch you want to deploy (usually `main` or `master`)
4. Choose the root folder as the source
5. Click Save

Your site will be available at `https://yourusername.github.io/repositoryname`
